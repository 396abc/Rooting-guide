# Rooting-guide
A rooting guide made for Android devices OS ver 14-16, tested on Nothing 4a Pro. Allows you to use wallet and cards as normal, essentially rooting with no drawbacks.
Also, this is legit. All of the tools used in the guide are open source, if you don't trust them, feel free to inspect the code yourself.
Though this repo has barely any content, it is legit. Mostly a passion project, and I thought I'd make a guide on how I got my rooted setup working.
A few sketchy things to look out for:
 - Some guides recommend installing Magisk's Kitsune version to fix DenyList not enforcing, this is discontinued and any sources claiming to have a working version of this CONTAIN MALWARE. I found this out firsthand (virustotal), if your DenyList isn't working, it probably just isn't appearing, or the item isn't supposed to be on a DenyList.
 - Be careful installing root apps that you cannot verify the integrity of (source code or if it contains malware), as they can gain full access to your phone. It is very recommended to only use open source tools for this reason.
